# BMI Calculator (Python)

A simple command-line BMI (Body Mass Index) calculator.
Created as part of the Oasis Infobyte Python Programming Internship (Task 2, Beginner Tier).

## Features
- Takes weight (kg) and height (meters) from the user
- Calculates BMI using: BMI = weight / (height x height)
- Shows the BMI value and category: Underweight, Normal, Overweight, Obese
- Input validation: rejects letters, zero and negative numbers
- Option to calculate again without restarting the program

## How to Run
1. Install Python 3
2. Open a terminal in this folder
3. Run: `python bmi_calculator.py`
4. Enter your weight and height when asked

## BMI Categories
| BMI | Category |
|-----|----------|
| Below 18.5 | Underweight |
| 18.5 - 24.9 | Normal |
| 25 - 29.9 | Overweight |
| 30 and above | Obese |
